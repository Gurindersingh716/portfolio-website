01 — About

/* Who I am */

I'm a backend engineer based in Bhopal, India, working primarily in Java and Spring Boot. My interest sits in the parts of a system people never see — data modelling, API design, authentication, and the decisions that determine whether an application still holds up a year later.

Alongside engineering, I've spent since January 2023 as a Technical Trainer at Vision Aid, teaching advanced Excel and technical computing to differently-abled learners. That work reshaped how I build software: accessibility isn't a compliance checkbox added at the end, it's an architectural decision made at the start. This site is built on that principle — semantic structure, full keyboard navigation, and screen reader support throughout.

I'm currently completing an MCA at VIT Bhopal University and looking for backend engineering roles where I can work on systems that matter.
