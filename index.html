01 — About

/* Who I am */

I'm a backend engineer based in Bhopal, India, working primarily in Java and Spring Boot. My interest sits in the parts of a system people never see — data modelling, API design, authentication, and the decisions that determine whether an application still holds up a year later.

Alongside engineering, I've spent since January 2023 as a Technical Trainer at Vision Aid, teaching advanced Excel and technical computing to differently-abled learners. That work reshaped how I build software: accessibility isn't a compliance checkbox added at the end, it's an architectural decision made at the start. This site is built on that principle — semantic structure, full keyboard navigation, and screen reader support throughout.

I also run what I build. Everything on this page is served from a Linux server I provisioned and configured myself — containers behind an Nginx reverse proxy, TLS certificates that renew on their own, application state kept in managed Postgres so the machine stays disposable. Writing an API and operating one turn out to be different skills, and I wanted both.

I'm currently completing an MCA at VIT Bhopal University and looking for backend engineering roles where I can work on systems that matter.

In production

Three services, one Ubuntu ARM instance I provision and maintain. Each sits behind Nginx with its own certificate; application data lives in managed Postgres, so the server itself holds no state and can be rebuilt from scratch.

How a request reaches this page.

—ms

Round trip to the API, measured from your browser

  1. A visitor's browser issues an HTTPS request.
  2. Cloudflare terminates TLS at the edge and serves the static site.
  3. API requests continue to the origin: an Oracle Cloud ARM instance in ap-mumbai-1.
  4. Nginx handles the certificate and reverse-proxies to the application.
  5. A Spring Boot service on Java 21, running in Docker, handles the request.
  6. It reads and writes to managed Neon Postgres over JDBC, then the response returns along the same path.

The host runs Nginx as a reverse proxy in front of two containers — a Spring Boot API on Java 21 and a FastAPI service for FPMIS — with the database hosted separately on Neon.
